# AI Impact on Jobs Prediction Portal

This is an advanced analytics dashboard that predicts the susceptibility of job roles to AI automation using Random Forest Regression.

## Features
- **Predictive Gauge:** Real-time risk assessment (0-100%).
- **Interactive Dashboard:** Dynamic charts and historical logs.
- **Admin Tools:** Settings for Dark Mode and Admin Profile customization.

## How to Run
1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Start the application:
   ```bash
   python app.py
   ```
3. Open your browser at `http://127.0.0.1:5000/`.
